# Project Management Capstone: Education Impact Initiative

A simulated end-to-end project management exercise completed for the Project Management
course (DAB-301) in the Data Analytics for Business program at St. Clair College.

## Overview

This repository contains the full set of project management deliverables produced for a
project assessing the impact of online vs. offline education on student performance and
engagement (September–November 2024). The project was conducted for St. Clair College's
Zekelman School of Business as a simulated initiative.

**My role:** Project Team Lead — coordinated a 5-person team through the complete project
lifecycle, from initiation through closing. Assigned task ownership, facilitated team
decisions, and resolved a scope and budget disagreement within the team to keep the
project on schedule.

## Project Summary

The project assessed student performance, engagement, satisfaction, and retention across
online and offline education modes, using survey data collected via Google Forms,
analyzed with Python and Tableau, and delivered as a full report with actionable
recommendations for the College.

- **Timeline:** September 13 – November 19, 2024
- **Budget:** $13,200
- **Team size:** 5
